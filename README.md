# Vivid

A privacy focused alternative YouTube frontend inspired by Invidious and Nitter

## Instances

- [Official Public Instance](https://vivid.errexe.xyz/)

## Self Hosting

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Youtube-Hackers/vivid.git
   cd vivid
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the frontend:
   ```bash
   npm run build
   ```

4. Start the server:
   ```bash
   npm start
   ```

The app will be available at `http://localhost:3067`.

## Architecture

Vivid is split into three main components:

- **Extractor**: the extracotr
- **Server**: the api server
- **Frontend**: the frontend
